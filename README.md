# Χτίζω πρόταση · ΣΥΝΟΙΔΑ

Ελληνική εφαρμογή δημιουργίας προτάσεων με εικόνες, για χρήση από browser. Δεν απαιτεί εγκατάσταση, λογαριασμό, server εφαρμογής ή εξωτερικές βιβλιοθήκες JavaScript.

## Χρήση

Άνοιξε το δημοσιευμένο URL, διάλεξε 2–5 μέλη και προαιρετικό χρόνο. Σύρε μια κάρτα στη θέση της ή πάτησε κάρτα και θέση. Η συμπληρωμένη θέση επιστρέφει την κάρτα με πάτημα. Το μικρό κουμπί μεγέθυνσης ανοίγει την εικόνα.

Το «Άλλο» ενεργοποιείται μόνο όταν υπάρχει επιμελημένη εναλλακτική που κρατά τα υπόλοιπα μέλη ίδια. Η αλλαγή ανανεώνει και τις εικόνες της πράξης/αιτίας όταν εξαρτώνται από το νέο πρόσωπο ή αντικείμενο.

Το «Σωστό!» απαιτεί συνεχές κράτημα 1 δευτερολέπτου (ποντίκι, αφή, Enter ή Space). Ακολουθεί η συμφωνημένη επιβράβευση χωρίς λευκό πλαίσιο, και μετά από άλλα 2 δευτερόλεπτα έρχεται διαφορετική πρόταση. Απελευθέρωση πριν από το 1 δευτερόλεπτο ακυρώνει το κράτημα. Αρχική ή απόκρυψη της καρτέλας ακυρώνει την εκκρεμή επιβράβευση.

## Συμβατότητα και ήχος

Στόχος: σύγχρονοι Safari/Chrome σε Mac, Safari σε iPad και Edge/Chrome σε Windows. Κοινός κώδικας Pointer Events για αφή, ποντίκι και γραφίδα, με εναλλακτικό χειρισμό μέσω πατημάτων και πληκτρολογίου. Πρόκειται για εφαρμογή web, όχι εγγενές πρόγραμμα του λειτουργικού.

Η εκφώνηση χρησιμοποιεί Web Speech API, `el-GR` και διαθέσιμη ελληνική φωνή. Οι φωνές παρέχονται από τη συσκευή/browser ([τεκμηρίωση](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesis/getVoices)). Αν δεν ξεκινά ο ήχος, έλεγξε την ένταση και την εγκατεστημένη ελληνική φωνή του λειτουργικού. Δεν αποστέλλουμε περιεχόμενο σε δικό μας server· μια διαδικτυακή φωνή μπορεί να χρησιμοποιεί την υπηρεσία του browser/λειτουργικού.

Οι πραγματικοί έλεγχοι και τα όριά τους καταγράφονται στο [docs/validation.md](docs/validation.md). Δεν εξισώνουμε τη δοκιμή διαστάσεων iPad σε Chromium με πραγματική δοκιμή Safari/iPadOS ή Windows.

## Δομή

- `data/content.json`: μοναδική πηγή προτάσεων, λεξιλογίου, χρονικών τύπων και αντιστοιχίσεων εικόνων.
- `src/engine.js`: επιμελημένες τράπεζες, ευρετήρια εναλλακτικών, κύκλος προτάσεων και κατάσταση τοποθέτησης.
- `src/app.js`: σύνδεση δεδομένων και χειριστηρίων.
- `src/gestures.js`, `src/reward.js`, `src/speech.js`, `src/images.js`: αφή/σύρσιμο, χρονισμός επιβράβευσης, ήχος και περιορισμένη προφόρτωση εικόνων.
- `styles/app.css`: εμφάνιση και προσαρμογή οθονών.
- `assets/pictures`: 450 επιλεγμένα WebP. Τα πρωτότυπα παραγωγής παραμένουν στο τοπικό αρχείο του έργου.
- `assets/fonts`: τοπικές γραμματοσειρές Inter/Comfortaa και άδειες OFL.

## Έλεγχοι και τοπική ανάπτυξη

Χρειάζεται Node.js 22+ μόνο για τα εργαλεία ελέγχου, όχι για τη χρήση της εφαρμογής. Δεν χρειάζεται `npm install`.

```sh
npm test
npm run validate
npm run review
python3 -m http.server 8767 --bind 127.0.0.1
```

Άνοιξε `http://127.0.0.1:8767/`. Η απευθείας χρήση `file://` δεν υποστηρίζει την ασφαλή φόρτωση JSON/modules· χρησιμοποίησε HTTP ή το δημοσιευμένο HTTPS URL.

Το `scripts/prepare-content.py` είναι το αρχικό εργαλείο εισαγωγής από τον τοπικό φάκελο αναβάθμισης και απαιτεί εκείνα τα staged αρχεία και fontTools/Brotli. Δεν εκτελείται στη φιλοξενία ή στην καθημερινή χρήση. Μετέπειτα αλλαγές γίνονται στο `data/content.json` και επαληθεύονται με τους παραπάνω ελέγχους. Οι κατάλογοι `sentence-review-lists.md`, `mode5-sentence-bank.md` και `docs/alternatives.md` παράγονται από τα ίδια δεδομένα.

## Ταχύτητα

Δεν προφορτώνεται όλη η βιβλιοθήκη. Φορτώνονται οι εικόνες της τρέχουσας και της επόμενης πρότασης, γίνεται αποκωδικοποίηση πριν την τοποθέτηση και χρησιμοποιείται προσωρινή μνήμη έως 64 καταχωρίσεων. Τα ευρετήρια εναλλακτικών κατασκευάζονται μία φορά. Το σύρσιμο ενημερώνει τη θέση μία φορά ανά frame.

Η βασική μεταφορά HTML/CSS/JS/JSON/λογοτύπου/γραμματοσειρών είναι περίπου 391 KB πριν από HTTP συμπίεση· οι εικόνες προστίθενται ανά πρόταση. Η βιβλιοθήκη εικόνων συνολικά είναι περίπου 14 MB, όχι κόστος αρχικής φόρτωσης. Οι τοπικές μετρήσεις δεν αποτελούν εγγύηση χρόνου μέσω Internet ή σε κάθε συσκευή.

Δημοσίευση: στατικά αρχεία στο υπάρχον GitHub Pages. Για νέα έκδοση κώδικα ενημέρωσε το version query στα module imports, HTML και fetch. Οι εικονογραφικές διορθώσεις έχουν νέα versioned ονόματα για ασφαλή ανανέωση cache. Δεν χρησιμοποιείται service worker που θα μπορούσε να κρατήσει παλιά εφαρμογή.

Το πρότυπο CI βρίσκεται στο `docs/validate-workflow.example.yml`. Η ενεργοποίησή του εκκρεμεί λόγω έλλειψης δικαιώματος OAuth `workflow` στη σύνδεση GitHub. Δεν εκτελέστηκαν απομακρυσμένα tests σε Windows/macOS/Linux.
