## Όρια

Οι μεγάλοι αριθμοί είναι τοπικά tests/mocks, όχι ταυτόχρονοι χρήστες ή φορτίο στον δημόσιο server. Οι έλεγχοι διαστάσεων δεν είναι πραγματικό Safari/iPadOS ή Windows. Δεν έγινε νέα ακουστική πιστοποίηση φωνής συσκευής. Οι προσομοιώσεις αποτυχιών έγιναν σε απομονωμένο τοπικό server, ο οποίος δεν περιλαμβάνεται στη δημοσίευση.
